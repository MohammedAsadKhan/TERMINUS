CONCEPT 05 / OPERATOR TTY

An austere console for analysts who think in signals, events, and commands. The interface borrows from terminal tooling, but keeps real labels, hierarchy, and accessible controls. Its visual identity comes from rhythm, linework, typography, and restrained phosphor color.

INTERACTION GRAMMAR

Keyboard first: 1–8 jump between sections, / focuses the command line, Esc exits it. Ledger rows imply arrow key movement, Enter to expand, and explicit commands for mutation. Responsive: the vertical index becomes a scrollable command strip; tables remain legible with horizontal scrolling. Color: green denotes system state and selection; amber signals review; red is reserved for severity. Dense information is grouped by rules and whitespace, with no rounded cards or dashboard tile ornament.
