# Terminus interface prototypes

Six standalone, full-screen console prototypes explore different visual systems for the same Terminus workflows. Each opens into an operational overview and lets you navigate to Incidents, Reports, Agent Fleet, Workflows, Integrations, Organization, and Settings. They use illustrative local data and actions; the production React/FastAPI console remains separate.
