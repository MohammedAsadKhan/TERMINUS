# The Analyst Atlas

Standalone interactive Terminus console concept. Open `index.html` in a browser. The sidebar switches among eight full-screen sections: Overview, Incidents, Reports, Agent fleet, Workflows, Integrations, Organization, and Settings.

The concept uses an editorial field-guide visual language in a practical SOC layout. The incident queue, search and state filters, and evidence dossier are central. The overview's asset topology is symbolic and explicitly labeled as non-geographic. Buttons and controls demonstrate UI behavior with local sample data; they do not call the Terminus API or persist changes.
